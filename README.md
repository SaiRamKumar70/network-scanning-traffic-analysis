# Network Scanning and Traffic Analysis Using Nmap and Wireshark

## Project Overview
This is a hands-on cybersecurity project focused on basic network scanning and traffic analysis using Nmap and Wireshark.

## Tools Used
- Nmap 7.993
- Wireshark
- Windows

## Practical Activities
- Performed a basic Nmap port scan on localhost (127.0.0.1).
- Identified open and closed TCP ports.
- Used Nmap service detection to identify running services.
- Captured network packets using Wireshark.
- Applied the DNS display filter to analyze DNS traffic.

## Scan Results
- Target: 127.0.0.1
- Host status: Up
- Open ports: 135/tcp and 445/tcp
- Closed ports: 998

## Project Structure
- `Nmap_Scan_Results/` – Nmap scan output files
- `Project_Report/` – Detailed Word project report
- `Screenshots/` – Practical screenshots
- `Wireshark_Captures/` – Packet capture evidence (kept locally)

## Learning Outcomes
- Basic network reconnaissance
- Port scanning
- Service detection
- Packet capture
- DNS traffic analysis

## Disclaimer
All scanning was performed on localhost (127.0.0.1), and packet capture was performed on my own laptop. Only authorized systems and networks should be tested.
